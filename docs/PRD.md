# PRD: Finsight

## 목표
CSV로 업로드한 거래내역/카드 명세서를 Claude API로 분석해서, 개인 소비자가 자신의 소비 패턴(카테고리별 지출, 월별 추이)을 한눈에 볼 수 있게 해주는 가계부 SaaS.

## 사용자
개인 소비자. 은행·카드사에서 내려받은 거래내역 CSV를 직접 업로드해 소비를 분석하고 싶은 사람. 국내 사용자를 우선 대상으로 하며(EUC-KR 등 인코딩 자동 대응 필요), 별도 회계 지식 없이도 이해할 수 있는 결과를 기대한다.

## 핵심 기능
1. Google OAuth 로그인 (Supabase Auth) — 이메일/비밀번호 회원가입은 지원하지 않는다.
2. CSV 업로드 → Claude API 분석 → 카테고리 자동분류(9종 고정: 식비/교통/주거·공과금/쇼핑/의료·건강/구독서비스/여가·문화/저축·투자/기타) + 월별 지출 요약을 대시보드에 표시.
3. 무료(월 3회 업로드) / 유료 구독(Polar 결제, 업로드 무제한) 티어.

## MVP 제외 사항
- 이상거래 탐지, 예산 추천/인사이트
- 카테고리 수동 수정 (분석 결과는 읽기 전용)
- 계정/데이터 삭제 셀프서비스 (문의 대응으로 처리)
- 취소/환불 거래의 원거래 상쇄 (스킵만 하고 합계 보정은 하지 않음 — 알려진 한계)
- 이메일/비밀번호 로그인
- Claude 외 다른 LLM(GPT 등) 지원

## 데이터 처리 정책
업로드된 CSV는 분석을 위해 Claude API로 전송된다. Anthropic API는 기본적으로 고객 데이터를 모델 학습에 사용하지 않는다(비학습 정책). 사용자 간 데이터는 Supabase RLS와 Storage 버킷 정책으로 격리되어, 본인 데이터만 조회·접근할 수 있다.

상세 사용자 시나리오·엣지 케이스·의사결정 근거는 `docs/plan.md`의 "시나리오 맵"을 참고한다.

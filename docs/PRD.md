# PRD: FinSight

## 목표
CSV 또는 PDF로 업로드한 거래내역/카드 명세서를 Claude API로 분석해서, 개인 소비자가 자신의 소비 패턴(카테고리별 지출, 월별 추이)을 한눈에 볼 수 있게 해주는 개인 지출 분석 SaaS(가계부).

## 사용자
자신의 카드·은행 지출을 손쉽게 이해하고 싶은 개인 소비자. 카드사 앱의 단편적 내역 대신, 은행·카드사에서 내려받은 명세서(CSV 또는 PDF)를 통째로 올려 "이번 달 어디에 얼마 썼는지"를 한눈에 보고 싶은 사람. 국내 사용자를 우선 대상으로 하며(EUC-KR/CP949 등 인코딩 자동 대응 필요), 별도 회계 지식 없이도 이해할 수 있는 결과를 기대한다.

## 핵심 기능
1. **Google OAuth 로그인** (Supabase Auth) — 이메일/비밀번호 회원가입은 지원하지 않는다.
2. **CSV/PDF 업로드 → AI 파싱**: 카드사별로 제각각인 CSV(인코딩·컬럼 편차)나 PDF 명세서(서버에서 텍스트 추출)를 Claude가 정규화된 거래 내역으로 변환. PDF는 텍스트 레이어가 있는 경우만 지원(스캔 이미지 PDF는 제외).
3. **자동 카테고리 분류 + 요약 인사이트**: 거래를 9종 고정 카테고리(식비/교통/주거·공과금/쇼핑/의료·건강/구독서비스/여가·문화/저축·투자/기타)로 묶고, "이번 달 식비 42만원(전체의 31%)…" 형태의 자연어 요약 제공.
4. **결과 대시보드**: 요약 카드 + 카테고리 도넛차트 + 월별 지출 추이 차트 + 거래 테이블.
5. **구독 결제**: Free(월 3회 업로드) / Pro(무제한 + 히스토리 보관). Polar 기반 월 구독.

## 과금 모델
- **Free**: 월 3회 업로드.
- **Pro (월 구독, 단일 티어)**: 무제한 업로드 + 히스토리 보관.
- 기능은 동일하고 **사용량(quota)으로 구분**. 앱은 `is_pro` 불리언으로 분기한다.
- **전환 지점**: Free quota 소진 후 재업로드 시 → 분석은 실행하되 **결과를 블러 처리 + 업그레이드 CTA** 노출.

## MVP 제외 사항
- 이상거래 탐지·절약조언(B인사이트), 대화형 Q&A(C인사이트)
- 카테고리 수동 수정 (분석 결과는 읽기 전용)
- 계정/데이터 삭제 셀프서비스 (문의 대응으로 처리)
- 취소/환불 거래의 원거래 상쇄 (스킵만 하고 합계 보정은 하지 않음 — 알려진 한계)
- 이메일/비밀번호 로그인
- Claude 외 다른 LLM(GPT 등) 지원
- 연간 요금제, 다중 티어(Basic 등)
- 다중 차트·필터·정렬 등 고급 대시보드 인터랙션 (기본 월별 추이 차트 1종은 포함)
- 백그라운드 잡/큐 (동기 처리로 대체)
- 후기·FAQ·데모 GIF 등 랜딩 부가 콘텐츠

## 데이터 처리 정책
업로드된 CSV/PDF는 분석을 위해 Claude API로 전송된다(카드번호·계좌번호 등은 마스킹한 사본만 전송). PDF는 서버에서 텍스트만 추출해 마스킹한 뒤 전송하며, 원본 PDF 바이너리는 Claude로 보내지 않는다. Anthropic API는 기본적으로 고객 데이터를 모델 학습에 사용하지 않는다(비학습 정책). 사용자 간 데이터는 Supabase RLS와 Storage 버킷 정책으로 격리되어, 본인 데이터만 조회·접근할 수 있다.
